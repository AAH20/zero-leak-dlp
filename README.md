## Highlights
- 100% Python Standard Library (Zero External Dependencies)
- In-Situ Sub-Millisecond Execution (< 0.02ms)
- Recursive Protocol Unpacker (Decodes Base64, Hex, URL-encoding & Nested JSON)
- High-Entropy Credential & Secret Scanner (API keys, AWS tokens, Private Keys, JWTs)
- Automatic Real-Time PII Redaction (SSNs, Emails, Credit Cards)
- Cryptographic SHA-256 AuditLedger for ISO 42001 & SOC 2 Type II
